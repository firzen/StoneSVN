# 样式与动效审校（2026-10-01）

[English](visual-audit-2026-10-01.md) | 简体中文

## 范围

对视觉规范、设计变量、全局样式、主布局、工作区、日志、提交、更新、对比、贮藏、追溯、检出、设置及共享组件进行了源码检查。浏览器复核使用本地 Vite 页面；确认框以相同 Element Plus 组件、类名和文本节点构造预览，不连接 SVN，也不执行还原或删除。

## 已修复

| 问题 | 修改 |
| --- | --- |
| 确认框清空内边距、标题和按钮贴边 | 恢复响应式内边距，统一 24px 圆角，约束视口宽度 |
| 普通对话框默认 padding 与分区 padding 叠加 | 外壳 padding 清零，关闭图标和标题预留空间 |
| 日志详情使用百分比宽度导致窄窗口过窄 | 改为最大 960px 和视口留白 |
| 动画工具类追加第二个缓动值，声明无效 | 删除重复缓动值 |
| 缺少全局减少动态效果支持 | 覆盖组件和库动画、过渡、延迟、平滑滚动及按下缩放 |
| 加载退出放大到 1.3 倍并动画化模糊，耗时 520ms | 250ms 淡出，最多放大到 1.05 倍 |
| 深色状态颜色覆盖局部语义状态，提交徽标和差异高亮固定浅色 | 改用成对状态变量，清除冗余覆盖 |
| 危险按钮沿用浅红背景配白字 | 使用深浅主题的错误色与配对文字色 |
| 输入框、卡片、深色导航圆角与规范不同 | 输入框和导航 8px，普通卡片 12px |
| 主按钮悬停色被后续统一规则覆盖 | 恢复主题主色悬停值 |
| 日志作者筛选聚焦使用固定颜色、工作区过渡使用 all | 使用主色 2px 焦点及明确的过渡属性 |

## 验证

- `npm run build` 通过；`npm run test:unit` 48 项通过（包括还原、删除确认流程及路径转义）。
- 全部引用的 `--app-*`、`--md-*` 变量有定义。
- 设置页在 390px 下浅色、深色截图检查通过；1280px 浅色布局检查通过。
- 确认框在 390px 和 1280px 下浅色、深色截图检查通过，长路径换行且按钮留在弹窗内部。1280px 实测内边距 24px，页面无横向溢出。
- 未在真实 Tauri 窗口执行 SVN 业务操作；有数据的日志、贮藏详情和其他页面仍需桌面集成验收。减少动态效果规则完成源码检查，系统媒体偏好切换尚未实测。

## 后续检查

历史样式仍有重复声明、固定颜色及特殊布局尺寸，特别是工作区欢迎页。保留现有布局，后续按组件迁移，不以本次修改宣称全部样式均已变量化。集成验收应包含长作者名、长提交信息、空列表、错误状态、键盘焦点、取消/关闭确认框，以及系统减少动态效果开启时的加载反馈。
