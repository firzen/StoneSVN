### Short Description (1-2 sentences)
MIT-licensed SVN desktop client for Windows, macOS and Linux, developed from OrcaSVN. It helps developers switch working copies, review diffs, choose files/directories to commit and shelve selected text hunks through the locally installed SVN CLI.

### Primary Language / Stack
Rust, Vue 3, TypeScript, Tauri 2
