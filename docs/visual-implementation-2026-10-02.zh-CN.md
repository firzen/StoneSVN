# 视觉规范落实记录（2026-10-02）

[English](visual-implementation-2026-10-02.md) | 简体中文

本次按视觉规范补齐已有实现，保留此前工作区确认框、焦点、主题和动效修复。

## 实现

- 工作区在 860px 以下改为上下排列文件列表与差异面板，修复差异面板被完全隐藏的问题；面板设定最小高度，内容在所属区域滚动。
- 欢迎页与局部导航移除固定灰白背景、蓝色选中色，复用表面、文字、分隔线和选中状态变量；窄窗口欢迎卡片收紧外边距与内边距。
- 全局滚动条、状态概览和深色差异样式改用语义变量，分段单选控件端部圆角改为 8px。
- 提交筛选工具栏与标签在窄窗口换行，搜索框占用可用宽度；贮藏页面过渡复用统一时长。

## 验证

`npm run build`、48 项前端单元测试通过。构建仍提示部分打包文件超过 500kB，这是现有体积提示。

浏览器使用本地 Vite 页面和内存中的模拟文件状态，不执行真实 SVN 写操作：

| 场景 | 结果 |
| --- | --- |
| 390px 工作区 | 深浅主题截图复核；文件面板与差异面板均可见，宽度 368px；外壳无横向溢出 |
| 1280px 工作区 | 文件与差异面板保持左右布局，外壳无横向溢出 |
| 文件点击 | 整行 outline 为 none，保留选中背景 |
| Tab 导航 | 实际控件匹配 focus-visible，并显示轮廓 |
| 浏览器模拟减少动态效果 | 媒体查询匹配，动画时长 0.01ms、迭代次数 1 |

浏览器媒体模拟不能替代操作系统偏好切换验收；真实 Tauri 工作副本的日志、提交、贮藏和错误恢复流程仍需桌面集成检查。历史样式的重复声明及特殊尺寸尚未全部清理，本记录不宣称所有页面完成所有状态的视觉验收。
