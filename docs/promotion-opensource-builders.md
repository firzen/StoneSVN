Add open source tool: StoneSVN
- Repository: https://github.com/firzen/StoneSVN
- Website: https://stonesvn.github.io/en/
- Description: MIT-licensed SVN desktop client for Windows, macOS and Linux. Reviews working-copy changes and diffs, selects file/directory commit scope, and stores local stashes of selected text hunks.
- Category: Development Tools
- Features: Multiple working copies, text diffs and image previews, selective file/directory commits, local text-hunk stashes, commit/file history, SVN property editing, five interface languages, light and dark themes.

Source and requirements:
- Developed from https://github.com/wustites/OrcaSVN with upstream attribution.
- Calls a separately installed SVN command-line client; this is a desktop application, not a hosted repository service.
- General Merge, Switch and line-level Blame interfaces are not currently available.
- macOS installers are ad-hoc signed and not notarized.
- License: https://github.com/firzen/StoneSVN/blob/main/LICENSE
- Published installers: https://github.com/firzen/StoneSVN/releases/latest
- Documentation: https://github.com/firzen/StoneSVN/blob/main/docs/user-guide.md
