- 项目地址：https://github.com/firzen/StoneSVN
- 项目官网：https://stonesvn.github.io/zh-CN/
- 语言类别：Rust、TypeScript、Vue
- 项目标题：StoneSVN，一个支持 Windows、macOS 和 Linux 的开源 SVN 桌面客户端
- 项目描述：面向仍在维护 SVN 仓库的开发者，将多工作副本切换、变更状态、文本差异与选择提交整合到一个工作台。支持按文件或目录选择提交，按文本变更块保存本地贮藏，查看文件历史、编辑 SVN 属性，并用全局忽略规则统一过滤临时文件。采用 Tauri、Rust 和 Vue 3，基于 OrcaSVN 继续开发，MIT 开源。
- 截图：官网提供浅色和深色工作台、属性页的虚构数据预览。

对于同时维护多个 SVN 工作副本的开发和运维人员，可以从项目栏切换副本，先审阅差异，再确定提交范围；未完成的修改可以本地贮藏后恢复。

当前公开版本为 v1.1.2，安装包见 https://github.com/firzen/StoneSVN/releases/latest 。需要另行安装本机 SVN CLI；macOS 安装包尚未经过苹果公证。通用 Merge、Switch 和逐行 Blame 界面尚未提供。

使用步骤与环境要求见 https://github.com/firzen/StoneSVN/blob/main/QUICKSTART.md 。欢迎试用和反馈。
