## Short description

Open-source SVN desktop client for reviewing working-copy changes, selecting commits and saving local text-hunk stashes.

## Description

StoneSVN is an MIT-licensed Subversion desktop client for Windows, macOS and Linux, developed from OrcaSVN. A project sidebar keeps multiple working copies available while you review file changes, inspect text diffs and image previews, choose a file or directory commit scope, browse history and edit SVN properties.

Local stashes can save selected text hunks and separately stored unversioned files. They remain application-managed local data, are not commits, and do not interoperate with native SVN shelves. The interface has five languages and light/dark themes.

StoneSVN requires an SVN command-line client installed separately. General Merge, Switch and line-level Blame interfaces are not currently available. macOS packages are ad-hoc signed and not notarized. Repository access uses your existing SVN credentials and permissions.
