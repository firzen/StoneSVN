# StoneSVN v1.1.5

[English](v1.1.5.md) | 简体中文

本次维护版本修复提交后的更新判断，并让远端状态检查正确使用已保存的 SSL 设置。

## 修复

- 根据 SVN 远端状态检查文件和属性变化，分别比较各节点的本地基准版本。工作副本根目录版本较旧时，不再把本地已有的提交计入待更新记录。
- 保留实际尚未取得的修改，包括同一作者从其他工作副本提交的变化、新增、删除、属性修改和切换分支后的子目录；筛选待更新提交后再应用显示数量限制。
- `svn status --show-updates` 正确使用对应服务器已保存的 TLS 和证书设置；纯本地状态扫描仍不增加联网元数据查询。
- 远端检查未完成或失败时显示相应状态，不再误报更新数量为 0；重试成功后清除此前的检查错误。
- SVN 命令失败且标准错误包含诊断信息时，提示不再夹带不完整的 XML；同步五种界面的更新状态文案。

各平台仍需单独安装 SVN 命令行工具。现有服务器例外设置仅作用于配置的 HTTPS 来源。macOS 构建采用临时签名，尚未公证。自动检查和打包不代表已完成所有系统的人工安装与启动验收。
