# OrcaSVN v0.6.2 发布准备

[English](v0.6.2.md) | 简体中文

比较基准：`v0.6.1`（`5427acf`）。范围包含其后的 5 个提交和本轮工作区修改。

## 更新内容

- 统一浅色/深色主题、字体、控件、文件状态徽标与滚动条，新增视觉设计规范，清理重复样式。
- 精简顶部工具栏，优化窄窗口导航、欢迎页面和主题选择。
- 工作区状态筛选和文件选择支持键盘操作，补充焦点样式及无障碍标签。
- 区分“工作区没有改动”和“筛选没有匹配文件”，补齐五种语言文案。
- 修复顶部仓库名、版本文字下沿裁切，限制超长内容宽度并提供完整内容提示。
- 页面外边距从 18px 缩小至 6px，内容面板圆角从 18px 缩小至 8px。
- 禁用 WebView 开发者工具及 Tauri 内部切换命令，拦截 F12、Ctrl+Shift+I/J/C 和 macOS 对应组合键，保留常用编辑操作；新增快捷键回归测试。

中英文公开发布说明已写入 `.github/workflows/tauri-build.yml`，保留原有各平台下载入口。

## 验收范围

- 2026-09-29 本地 `npm run check` 通过：前端类型检查、生产构建、9 项前端测试、Rust 格式检查和 35 项 Rust 测试全部通过。Vite 仍提示部分产物超过 500 kB，不影响本次构建通过。
- 发布前需桌面验收：重启后调试快捷键不打开控制台；长仓库名/版本、紧凑面板在浅色和深色主题下显示正常；检查窄窗口与系统缩放。
- 既有待验收项：日志日期筛选显示，以及差异页面长路径原始场景，详见 `todo.md`。本版不宣称这些问题已验收解决。
- Windows、macOS、Linux 安装包由标签发布流水线构建；本地检查不能替代跨平台安装验证。

## 发布步骤

1. 完成桌面验收，确认版本配置及锁文件均为 0.6.2。
2. 提交本次发布范围的修改并推送代码。
3. 创建并推送 `v0.6.2` 标签；该操作会触发三平台构建并公开发布 GitHub Release，随后尝试发布 WinGet。
4. 检查流水线、安装包下载链接及安装启动结果。

2026-09-29 已确认执行发布，使用 `v0.6.2` 标签触发流水线。实际构建与公开发布状态以 GitHub Actions 和 Release 页面为准。
