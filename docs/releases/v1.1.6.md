# StoneSVN v1.1.6

English | [简体中文](v1.1.6.zh-CN.md)

This release improves remote update review, preserves the files changed by an update, and keeps the macOS workspace available after closing its window.

## Improvements

- Review incoming revisions and their changed paths in one panel. Switch between incoming revisions and the latest update result; filter file lists by status or path, group by directory, and copy paths.
- Keep the actual changed files visible after an update, including additions, deletions, property changes, and conflicts. Double-click a file to compare its before/after repository revisions; directory rows retain their folder identity.
- Show update progress, completion time, conflicts, command output, and unavailable result details. Finish the local refresh before checking remote history in the background, so a slow history query does not keep the update busy.
- Return the remote revision and incoming history from the same status check. Reuse local inventory baselines during forced refreshes and avoid extra repository URL probes for local metadata queries.
- On macOS, closing the main window hides it while retaining workspace state. Click the Dock icon to reopen it; explicit Quit still exits the application.
- Update all five interface languages and fictional capture data for the new update views.

Install the SVN CLI separately on every platform. Update results describe repository changes, not uncommitted local edits. macOS builds are ad-hoc signed and not notarized. Automated checks and packaging do not establish manual installation or startup acceptance on every operating system.
