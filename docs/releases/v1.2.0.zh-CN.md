# StoneSVN v1.2.0

[English](v1.2.0.md) | 简体中文

通过双栏对比审阅和处理 SVN 冲突，工作区提供精简的只读预览。

## 冲突对比

- 通过对齐行号、语法高亮、同步滚动和搜索，对照传入内容与本地结果。在完整对比页切换传入、本地和可读取的共同原文，逐段选择内容或编辑结果，确认后再应用。
- SVN 属性冲突与文件正文分别展示。应用已确认的属性值时保留正文及无关属性；无法可靠读取冲突值时，提供原始说明供手动处理。
- 根据本地与传入版本的操作解释树冲突。对于「本地编辑、传入删除」的文件，可保留本地文件，或确认后接受删除；其他树冲突须先手动整理文件，再标记解决。
- 应用前重新核对已审阅的冲突状态，防止过期预览覆盖加载后发生的修改。解决后仍需检查并单独提交。

## 工作区与更新改进

- 冲突文件置顶，包含仅属性冲突的文件。双击冲突文件或点击「解决冲突」图标进入完整对比；工作区预览保持只读。
- 「工作区」工具栏图标显示黄色冲突数量微标；冲突行统一使用解决入口，移除重复的对比按钮。
- 「更新」显示待获取的远端提交数量，工具栏与更新页共享检查结果。后台检查失败时保留上次已知数量，并提示检查失败状态。
- 支持 F5 和 macOS Command-R 刷新本地状态，无需重新加载应用；拓宽时间线版本列，便于显示较长的版本号。

各平台均需单独安装 SVN CLI。二进制或无法读取的内容，以及不支持的属性或树冲突格式，可能需要外部编辑器或 SVN 工具处理。macOS 构建采用临时签名，未经公证。自动检查和打包不代表已在所有操作系统完成手动安装和启动验收。
