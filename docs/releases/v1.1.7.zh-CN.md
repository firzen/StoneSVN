# StoneSVN v1.1.7

[English](v1.1.7.md) | 简体中文

本版优化工作副本存在大量远端新增内容时，待更新版本列表加载缓慢的问题。

## 修复

- 将远端新增文件和目录的历史记录合并查询，每批最多 64 个路径，避免为每个新增项单独发送请求。已有节点仍按各自的 BASE 版本判断，切换目录仍使用实际仓库地址。
- 分别保留新增路径的创建边界，待更新版本保持去重和排序，并在筛选后应用配置的显示数量限制。
- 增加真实 SVN 集成测试，覆盖 70 多个新增文件、嵌套目录、中文、空格、`@`、`%` 路径及版本数量限制。

各平台均需单独安装 SVN CLI。macOS 安装包使用临时签名，未经公证。自动检查和打包不代表已在所有操作系统完成手工安装、启动验收。
