# OrcaSVN v0.6.3

English | [简体中文](v0.6.3.zh-CN.md)

## What's new since v0.6.2

- Persist and verify workspace status snapshots, reuse unchanged state, and query small sets of changed paths. Use the NTFS USN journal when available, with filesystem metadata scans as the fallback.
- Wait for SVN processes asynchronously, drain both output streams, and remove the previous 100 ms completion polling interval.
- Virtualize workspace files, diffs, and file navigation. Add full-text diff search, match navigation, Ctrl/Cmd+F, full copy, and worker indexing for large documents.
- Use revision cursors for explicit 20-entry log pages, including author, keyword, and date filters; preserve full author and message text in hover previews.
- Move ignore matching to a worker, share refresh requests, and reject outdated asynchronous results.
- Align themes, dialogs, motion, and narrow layouts, and expand the user guide and performance documentation.
- Check ancestor SVN administrative metadata when opening a working-copy subdirectory, and refresh shared workspace state after an update even if its page has been deactivated.
- Normalize Windows status paths, confirm destructive workspace actions, and restrict mutations while cached state remains unverified.

The Linux Release benchmark shows substantial gains for unchanged refreshes and cached reopening. The measured 10,000-file first-load improvement is smaller. These are native data-request measurements, not desktop startup or Windows performance claims.


## Benchmark scope

On Linux aarch64 with a Release build and a warm 10,000-file local working copy, native-data median unchanged refresh fell from 100.7 to 20.4 ms, cached reopening from 100.7 to 29.5 ms, and first load without application cache from 101.0 to 82.8 ms. Each scenario ran 15 times and includes the local revision query; first load also includes repository metadata. WebView startup/rendering, Windows, cold storage, and arbitrary real repositories are not represented. See the [benchmark methodology](https://github.com/wustites/OrcaSVN/blob/v0.6.3/docs/workspace-startup-benchmark.md).

The snapshot format upgrade rebuilds old native caches once. Destructive confirmations show the full target path and become invalid when the workspace or target state changes.

## Downloads
