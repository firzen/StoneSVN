# StoneSVN v1.0.0

English | [简体中文](v1.0.0.zh-CN.md)

StoneSVN 1.0.0 is the first independent stable release. Installers are distributed through this project's GitHub Releases; the former OrcaSVN WinGet package is not used.

- Persistent project sidebar with local/remote working-copy entry points, sorting, resizing, and per-project session state.
- Updated StoneSVN branding, light/dark themes, and compact workbench controls.
- Text and image previews, configurable file filters, and independent file/directory commit selection with range selection.
- Property browser with recursive search, SVN property editing, export without `.svn` metadata, scheduled deletion, and restoration of clean versioned files to a specified revision.
- Paginated commit timeline and file history with historical diffs and adjacent-revision navigation.
- Local stashes, five interface languages, and Unicode SVN path support.

Download a Windows x64 EXE/MSI, macOS Apple Silicon (aarch64), macOS Intel (x64), or Linux x64 installer from Assets. A locally installed SVN CLI is required. Switch, general-purpose Merge, and conflict Resolve still require another SVN client or the command line.

[User guide](https://github.com/firzen/StoneSVN/blob/v1.0.0/docs/user-guide.md)

## Cross-platform fixes

- Convert normalized Windows local paths to SVN-compatible paths for export, property edits, and revision restoration; retain escaping for filenames containing `@`.
- Query Windows file metadata directly so stale directory-enumeration timestamps do not hide same-size edits. Local repository tests use cross-platform `file:///` URLs.
- Pass property values through temporary files to avoid Windows `*` expansion while preserving UTF-8, multiline, and empty values.
- Normalize Windows XML line endings while retaining explicitly encoded carriage returns, avoiding false property changes after reading.
