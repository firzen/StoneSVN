# StoneSVN v1.1.8

English | [简体中文](v1.1.8.zh-CN.md)

This release makes it easier to select diff content and open the file being reviewed.

## Improvements

- Keep line numbers and gutter markers (`+`, `-`, and `@`) out of selected and copied diff text, including selections spanning multiple rows. Symbols within the file content are preserved. Add WebKit selection compatibility for macOS.
- Add small open icons to the workspace file list, workspace preview header, and comparison header. When the local preview supports opening, use the system default application to open that working-copy file or directory. Historical previews and missing files do not show this action.

Install the SVN CLI separately on every platform. macOS builds are ad-hoc signed and not notarized. Automated checks and packaging do not establish manual installation or startup acceptance on every operating system.
