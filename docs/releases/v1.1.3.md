# StoneSVN v1.1.3

English | [简体中文](v1.1.3.zh-CN.md)

This maintenance release improves release reliability and documentation. Application features remain the same as v1.1.2.

## Improvements

- Gate stable tags and publication on successful checks and installer packaging for Linux x64, Windows x64, macOS Apple Silicon, and macOS Intel; verify all nine distribution files before publishing.
- Preserve the official Tauri macOS DMG build environment with bounded retries, keep validation runs independent from publication, and preserve Windows CRLF line endings during version preparation.
- Validate all six version values, full release notes, and reviewed website summaries in five languages before release preparation or publication.
- Expand the quickstart with illustrated workflows; provide English documentation with Simplified Chinese translations and language-matched screenshots for all five README locales.
- Automate website release metadata, download links, and 15 localized screenshots using capture tools and browser dependencies pinned to the published source; document deployment checks and retries.

Install the SVN CLI separately on every platform. macOS builds are ad-hoc signed and not notarized. Automated checks and packaging do not establish manual installation or startup acceptance on every operating system.
