# StoneSVN v1.1.5

English | [简体中文](v1.1.5.zh-CN.md)

This maintenance release fixes update detection after commits and restores saved SSL settings during remote status checks.

## Fixes

- Detect incoming file and property changes with SVN remote status, comparing each node with its own BASE revision. A mixed-revision working copy no longer lists already-applied commits just because its root directory has an older revision.
- Keep genuinely missing changes visible, including changes made by the same author in another working copy, additions, deletions, property changes, and switched subtrees. Apply the history limit after filtering incoming commits.
- Reuse saved server-specific TLS and certificate settings for `svn status --show-updates`. Local-only status scans continue to run without a network metadata query.
- Show a failed or unchecked state when remote checking cannot finish, instead of reporting zero updates. A successful retry clears the previous check error.
- Remove partial XML from failed SVN command messages when stderr contains the actual diagnostic. Synchronize update-state messages across all five interface languages.

Install the SVN CLI separately on every platform. Existing server exceptions remain scoped to their configured HTTPS origin. macOS builds are ad-hoc signed and not notarized. Automated checks and packaging do not establish manual installation or startup acceptance on every operating system.
