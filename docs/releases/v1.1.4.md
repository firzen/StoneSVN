# StoneSVN v1.1.4

English | [简体中文](v1.1.4.zh-CN.md)

This release improves commit review and makes code diffs easier to read.

## Improvements

- Stay on the Commit page after committing, keeping command output visible while refreshing file status.
- Add Revert and Trace before Diff in commit rows. Revert previews the affected files and asks for confirmation; Trace opens the file's revision history. Unsupported actions are hidden for the relevant file states and directories.
- Double-click a file row in the Commit page to open its diff. Action buttons and checkboxes keep their own behavior.
- Add minus/plus font-size controls to text diff viewers, including workspace previews. Adjust from 10 to 28 pixels in one-pixel steps; the saved size is shared across views and retained after restarting. Line height and horizontal scrolling follow the selected size.
- Update English and Simplified Chinese usage documentation and all five interface translations for font controls.

Install the SVN CLI separately on every platform. Trace shows file revision history, not line-by-line annotations. macOS builds are ad-hoc signed and not notarized. Automated checks and packaging do not establish manual installation or startup acceptance on every operating system.
