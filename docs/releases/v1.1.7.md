# StoneSVN v1.1.7

English | [简体中文](v1.1.7.zh-CN.md)

This release reduces the time needed to load incoming revisions when a working copy has many remote additions.

## Fixes

- Query the history of remote additions in batches of up to 64 paths instead of issuing a separate request for every new file or directory. Existing nodes retain their own BASE revisions, and switched subtrees use their actual repository URLs. Names with a space or dot before `@` use full URL queries to preserve them on Windows.
- Preserve separate creation boundaries for new paths, keep incoming revisions deduplicated and ordered, and apply the configured display limit after filtering.
- Add SVN integration coverage for more than 70 incoming files, nested directories, Chinese names, spaces, `@`, `%`, and revision limits.

Install the SVN CLI separately on every platform. macOS builds are ad-hoc signed and not notarized. Automated checks and packaging do not establish manual installation or startup acceptance on every operating system.
