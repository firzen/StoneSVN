# StoneSVN v1.1.9

English | [简体中文](v1.1.9.zh-CN.md)

Open directories directly from the commit view while reviewing changes.

## Improvements

- Double-click a directory in the commit change list to open it in Finder or the system file manager, including grouping directories, empty directories, and the working-copy root. Files continue to open their diff on double-click. Opening failures appear in the output area.
- Reuse the checked frontend during release packaging and isolate complete build caches by platform.
- Update promotion follow-up audit documentation.

Install the SVN CLI separately on every platform. macOS builds are ad-hoc signed and not notarized. Automated checks and packaging do not establish manual installation or startup acceptance on every operating system.
