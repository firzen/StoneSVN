# StoneSVN v1.2.1

English | [简体中文](v1.2.1.zh-CN.md)

- Keep the toolbar on one row at narrow desktop window widths, leaving more vertical space for the workspace.
- Below 1024 pixels, hide the toolbar language shortcut. Language selection remains available under Settings → Appearance. Below 940 pixels, show the application icon by itself and tighten button spacing.
- Show the conflict and incoming revision badges in the localized website workspace screenshots using fictional data.

Install the SVN CLI separately on each platform. macOS builds are ad-hoc signed.
