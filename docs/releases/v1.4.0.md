## Export the changes in a commit

- Open a timeline record and choose **Export this revision's changes** to save a snapshot of only the paths changed in that revision. The export keeps repository-relative folders and reads file contents from the selected revision, not from local working-copy edits.
- Added and replaced files or directories are exported in full. Modified files and directories whose only change is to properties are exported at that revision. Deleted paths, unchanged descendants of changed directories, SVN externals, and `.svn` metadata are not included.
- Choose a new destination in the existing save dialog, defaulting to `<workspace>-r<revision>`. Existing directories are never overwritten, and exporting inside the current workspace is rejected.
- Large exports use an extended timeout, reuse the in-app authentication and TLS prompts, and remove an incomplete directory if the export fails. The working copy is not modified.
