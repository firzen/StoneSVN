# StoneSVN v1.0.2

[English](v1.0.2.md) | 简体中文

- macOS 安装包采用免费的 Ad-hoc 签名，无需苹果开发者账号；Intel（`x64`）和 Apple Silicon（`aarch64`）版本均使用此配置。
- 补充各语言 README 的首次打开说明，以及 macOS 本地构建、签名验证和分发指南。

## 安装说明

macOS 安装包未经过苹果公证。将 StoneSVN 拖入「应用程序」，首次打开若被系统阻止，请在「系统设置 → 隐私与安全性 → 仍要打开」中放行，再确认「打开」。公司管理的 Mac 可能需要 IT 放行。无需关闭整个系统的安全检查。

所有平台仍需安装本机 SVN CLI；macOS 使用 Homebrew 的用户可执行 `brew install subversion`。

## English

- Use ad-hoc signatures for both Intel and Apple Silicon macOS builds, without Apple signing credentials.

macOS builds are not notarized. Drag StoneSVN into Applications. If the first launch is blocked, use System Settings → Privacy & Security → Open Anyway, then confirm Open. Managed Macs may require IT approval. SVN CLI must be installed separately.
