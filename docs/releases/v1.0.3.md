# StoneSVN v1.0.3

English | [简体中文](v1.0.3.zh-CN.md)

- Show installation and first-launch instructions directly in the macOS DMG window.
- Drag StoneSVN into Applications. If the first launch is blocked, try opening the app first, then use System Settings → Privacy & Security → Open Anyway → Open.
- Builds remain ad-hoc signed and are not notarized by Apple. Install the SVN CLI separately.
