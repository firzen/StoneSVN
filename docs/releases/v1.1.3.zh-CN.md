# StoneSVN v1.1.3

[English](v1.1.3.md) | 简体中文

本次维护更新改进发布可靠性与使用文档，应用功能与 v1.1.2 保持一致。

## 改进

- Linux x64、Windows x64、macOS Apple Silicon 和 macOS Intel 全部通过检查及安装包构建后，才创建正式标签并发布；公开前校验九个分发文件。
- 保留 Tauri 官方 macOS DMG 构建环境并进行有限次数重试；验证任务与正式发布独立；版本准备保留 Windows CRLF 换行符。
- 准备或发布版本前，校验六处版本值、完整发布说明及经过审核的五语言官网摘要。
- 扩充带图解的快速入门；默认提供英文文档及简体中文译文，为五种语言的 README 配套相应语言截图。
- 官网使用固定于发布源码的截图工具与浏览器依赖，自动同步版本信息、下载链接和 15 张本地化截图，并完善部署验收与重试说明。

各平台仍需另行安装 SVN CLI。macOS 安装包使用 Ad-hoc 签名，未经过 Apple 公证。自动检查和打包不代表已在每个操作系统上完成手动安装、启动验收。
