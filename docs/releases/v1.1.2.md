# StoneSVN v1.1.2

English | [简体中文](v1.1.2.zh-CN.md)

This release expands everyday working-copy actions, with improvements to Properties, conflict resolution, and change confirmation.

## Improvements

- Resolve conflicts from Workspace or Properties using manually resolved content, the local version, or the repository version. Organize directory/tree conflicts manually first.
- Rename and move versioned files or directories while preserving history. Directory move commits validate both source and destination scopes.
- Preview the full affected tree before recursive revert, including vulnerable unversioned content inside copied/moved directories. Revalidate the scope before execution.
- Restore clean, complete, single-revision directories to a historical revision as local changes for review and a separate commit.
- Add unversioned items or cancel plain scheduled additions without deleting local files. Copies and moves are excluded from plain-add cancellation.
- Relocate a working copy when the same SVN repository changes address, retaining SVN identity validation and leaving external working copies separate.
- Move property actions to the page header, show descendant status badges, and retain the current page when switching projects.
- Update five-language documentation and the website, including localized screenshots and automatic latest stable release downloads.

Review and commit resulting changes separately. Revert discards local modifications. General Merge, Switch and line-by-line Blame interfaces remain unavailable. macOS builds are ad-hoc signed and not notarized; install the SVN CLI separately on every platform.
