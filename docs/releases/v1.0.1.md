# StoneSVN v1.0.1

English | [简体中文](v1.0.1.zh-CN.md)

- Discover SVN in PATH and common installation locations on Windows, macOS, and Linux. Explicit custom paths remain authoritative.
- Require a validated executable path before opening workspaces when detection fails. Allow manual entry, file selection, and retrying automatic detection; persist only valid configurations.
- Keep workspace load errors visible instead of silently returning to the welcome screen.
- Provide separate Intel and Apple Silicon macOS installers with architecture checks.

- Show symbolic link targets in the property inspector, with read-only handling for external or broken links and checks against traversal through linked parent directories.
- Widen the log date column and keep timestamps on one line.

The native regression test starts a separate process with a Finder-style PATH, discovers SVN, creates and checks out a local repository, and reads working-copy status and metadata.

An explicitly invalid executable path still returns an error. Download Windows x64 EXE/MSI, macOS Intel x64 or Apple Silicon aarch64 DMG, or Linux x64 DEB/RPM/AppImage from Assets. Install the SVN CLI separately.
