# OrcaSVN v0.6.4

English | [简体中文](v0.6.4.zh-CN.md)

## Fixes since v0.6.3

- Run SVN subprocesses with a UTF-8 locale on macOS and Linux so missing, ASCII, or invalid inherited locales do not corrupt Chinese paths, repository URLs, commit messages, or command output. This addresses the filename encoding problem reported in [#7](https://github.com/wustites/OrcaSVN/issues/7).
- Add a real local-repository regression test covering checkout to Chinese working-copy paths, adding and committing Chinese filenames and messages, and checking out a Chinese subdirectory URL under each affected parent locale configuration.

The locale-related Chinese-path failure was reproduced on Linux, and the regression test passes with the fix. Confirmation of the original GUI errors on macOS 15.7.4 with SVN 1.15.0 is still requested from the reporter; the issue remains open.


## Downloads

Choose Windows NSIS EXE/MSI, macOS Apple Silicon, or Linux x64 assets. A local SVN CLI remains required.
