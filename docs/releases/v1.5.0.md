# StoneSVN v1.5.0

## Improvements

- Browse the remote repository before checkout from Add Remote Copy. The URL field's Browse button opens a file-tree dialog showing directories and files with the same icons and typography as Properties.
- Select a directory and confirm to update the checkout URL directly. The entered project is selected by default; double-click directories to expand or collapse them. Files are shown for context and cannot be selected for checkout.
- Browse the requested revision with existing authentication and TLS prompts, lazy directory loading, retryable errors, and protection against stale requests.
- Collect unique recent commit messages across log batches.
