### 😳 Explain why it should be added

StoneSVN is an MIT-licensed SVN desktop client, developed from OrcaSVN using Tauri, Rust and Vue 3. It would fit the **Version Control** category, alongside existing SVN clients such as Cornerstone and Versions.

It offers a graphical workspace for developers who still use Subversion: switch between working copies, review text diffs, choose files or directories for commits, and shelve selected text hunks locally. macOS builds are available for both Apple Silicon and Intel; Windows and Linux builds are also provided.

Suggested concise listing description:

> Open-source SVN client for reviewing changes, selecting commits, and shelving local modifications.

### 📖 Additional context

Current release: v1.1.2. The application requires a locally installed SVN CLI. macOS builds are ad-hoc signed and not notarized. General Merge, Switch, and line-by-line Blame interfaces are not available.

The website provides light and dark workspace previews with fictional project data. The project is a fork of OrcaSVN, with its source and MIT license available in the repository.
