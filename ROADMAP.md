# Roadmap

English | [简体中文](ROADMAP.zh-CN.md)

## Near term

- Add bulk selection and consistent confirmation flows for workspace Add, Delete, Resolve, and Revert.
- Show SVN operation results in a consistent, copyable operation log.
- Expand automated coverage for status filtering, diff parsing, and command argument construction.

## Medium term

- Add credential and certificate interactions instead of relying only on `--non-interactive`.
- Provide visual navigation for branches, tags, and merge history.
- Support pre-commit checks and configurable ignore rules.
- Add keyboard shortcuts and a command palette.

## Long term

- Provide incremental status refresh for large repositories.
- Improve accessibility and high-contrast themes.
- Establish a compatibility matrix covering multiple SVN CLI versions and operating systems.
